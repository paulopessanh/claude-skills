# Brand process canon: the eight-stage chain

Confidence key: 🟢 published primary source · 🟡 secondary or this skill's own synthesis · 🔴 folklore, do not rely on it.

## The chain this skill uses

`briefing -> research -> strategy -> concept -> visual_direction -> system -> applications -> guidelines`

🟡 The eight stages are this skill's own synthesis. They split the practitioner phases below so
that each stage has one decision set and one gate question. They are not a quoted standard.

| Stage | Decisions it must make | Observable from outside? |
|---|---|---|
| briefing | objectives, audience scope, constraints | No. Intent only |
| research | market audit, audience insight, competitor map | No, except through a published case study |
| strategy | positioning, personality, promise, audience | Rarely. Infer from outputs |
| concept | big idea, naming logic, voice | Partly: the name, the line, the tone |
| visual_direction | logo concept, colour logic, type logic, imagery | Yes |
| system | grid, lockups, tokens, motion | Yes, if you see several applications |
| applications | key touchpoints, packaging, digital | Yes |
| guidelines | clear space, usage rules, governance | Only if published |

## How the sources map

1. 🟢 Alina Wheeler, *Designing Brand Identity*, 5th ed., Wiley, 2017. Five phases: conducting
   research, clarifying strategy, designing identity, creating touchpoints, managing assets.
   Our briefing and research map to phase 1, strategy and concept to phase 2, visual_direction
   and system to phase 3, applications to phase 4, guidelines to phase 5.
2. 🟢 Marty Neumeier, *The Brand Gap*, New Riders, 2003 (revised 2006). Five disciplines:
   differentiate, collaborate, innovate, validate, cultivate. Source for treating the gap
   between strategy and design as the place where identities fail.
3. 🟢 Jean-Noël Kapferer, *The New Strategic Brand Management*, Kogan Page (several editions).
   The identity prism: physique, personality, culture, relationship, reflection, self-image.
   Use it to name what a strategy stage decided about personality.
4. 🟢 David A. Aaker, *Building Strong Brands*, Free Press, 1996. Brand identity planning:
   core and extended identity. Use it to separate the one thing from the supporting things.
5. 🟢 Al Ries and Jack Trout, *Positioning: The Battle for Your Mind*, 1981. Positioning is
   relative to competitors, which is why the strategy gate asks for a competitor's version.
6. 🟡 Wally Olins, *On Brand*, Thames & Hudson, 2003. Identity as the visible expression of
   a strategy; useful for the back-propagation step (output implies input).
7. 🟢 W3C, *Web Content Accessibility Guidelines 2.1*, SC 1.4.3: contrast ratio 4.5:1 for
   normal text, 3:1 for large text. The palette tool uses these grades.

## Visual-system facts the tools rely on

- 🟢 Contrast ratio is (L1 + 0.05) / (L2 + 0.05) on WCAG relative luminance.
- 🟢 Josef Albers, *Interaction of Color*, Yale University Press, 1963: a colour is read
  relative to its neighbours, which is why shares and grounds matter as much as hex values.
- 🟢 Ellen Lupton, *Thinking with Type*, Princeton Architectural Press, 2nd ed., 2010:
  pairing by contrast of class and role; used for the serif/sans reading.
- 🟡 The tool's hue-relation bands (complementary 165-180 degrees, and so on) are working
  heuristics for sorting palettes, not standards.

## Folklore to refuse

- 🔴 "60-30-10 is a rule." It is an interior-design rule of thumb. The tool reports shares as
  observations and never scores them against it.
- 🔴 "Every logo has a hidden meaning." Some do. Most readings are added after the fact.
- 🔴 "This identity took X minutes or cost Y." Unless a primary source says so, it is a story.
